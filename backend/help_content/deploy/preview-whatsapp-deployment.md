# Preview WhatsApp deployment

This guide explains the **Preview WhatsApp deployment** workflow in the current Northstar product.

## Before you start

This guide is available to all authenticated workspace roles.

## Steps

1. Open **Deploy** from the Northstar application and select the relevant agent, conversation, lead, integration, deployment, or workspace setting.
2. Review the current state before making a change.
3. Use the labeled control described by this guide and save/apply when the UI requires it.
4. Verify the result in the same page or its corresponding preview/status view.

## What happens next

Northstar keeps this action inside the existing authenticated workspace and applies backend role/tenant checks.

## Troubleshooting

If the action is missing or rejected, confirm your workspace role and current product state, then use Help search or Contact support with safe diagnostics. Do not bypass backend authorization.
